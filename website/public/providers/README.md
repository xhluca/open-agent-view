# Provider marks

These files are local presentation assets so the public website makes no
third-party image requests at runtime.

- `claude.svg`, `opencode.svg`, `cursor.svg`, `copilot.svg`,
  `antigravity.svg`, and `terminal.svg` are compact marks from
  [Simple Icons](https://simpleicons.org/), distributed under CC0 1.0.
- `pi.svg` is Pi's official square badge from its
  [press kit](https://pi.dev/press-kit) (`pi.dev/favicon.svg`, MIT).
- `codex.png` is the existing local OpenAI mark used by this project.
- `mistral-vibe.svg` is Mistral Vibe's project icon from the official
  [`mistralai/mistral-vibe`](https://github.com/mistralai/mistral-vibe/blob/main/distribution/zed/icons/mistral_vibe.svg)
  repository (Apache-2.0).
- `qwen.svg` is Qwen Code's project mark from the official
  [`QwenLM/qwen-code`](https://github.com/QwenLM/qwen-code/blob/main/packages/desktop-shell/bootstrap/qwen-code-logo.svg)
  repository (Apache-2.0).
- Muse Code and Kimi Code use compact text monograms. Muse's distributed CLI
  does not publish a reusable standalone mark, while the official Kimi brand
  repository does not declare an asset license. The site therefore does not
  invent, hotlink, or copy an ambiguously licensed logo for either provider.

Names and logos may be trademarks of their respective owners. Their inclusion
describes compatibility and does not imply endorsement.
